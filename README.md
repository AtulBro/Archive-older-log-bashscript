# Archive-older-log-bashscript

## Project Requirement
Archvive Older Log -  A Bash-based tool that scans a specified directory and identifies files larger than a given size (e.g., 15 MB) or older than a specified number of days (e.g., 10 days).
compress those file and move in a 'archive' folder.

## Step of script
1. Provide the path of directory
2. Check if the directory is present or not
3. Create 'archive' folder. If not already presnt
4. Find all the file with more than given size eg., 20Mb
5. Compress each file
6. Move the compressed file in 'archive' folder
